# Glossary

Shared terms used by this repository's customizations.

| Term | Meaning |
|------|---------|
| Perspective | A review assignment that owns one question about the deliverable. Code uses Intent, Failure, and Maintenance; writing uses Purpose & Audience, Evidence & Consistency, and Style & Tone. A perspective is not a model identity. |
| Assessment | A perspective's answer to its owned question, shown as a concise status. It is not an overall merge or publishing vote. |
| Combined recommendation | One coordinating-agent synthesis of all three assessments, coverage, and unresolved review concerns. It supports the user's decision without authorizing merge or publication. |
| Review preferences | The profile and model/reasoning choices saved for one summary. They are kept separate from effective runtime metadata and current review results; repeated model selections are allowed. |
